# exp_003 — Findings: synthetic media matrix and multi-track determinism

**Date:** 2026-11-22
**Hypothesis:** [HYPOTHESIS.md](HYPOTHESIS.md)
**Configs:** `exp_results/media-a.toml`, `exp_results/media-b.toml`

## What happened

Two independent runs of `wormhole-harness media` with identical config except
the output directory produced 11 files each: 6 I420 video files (main + 5
profiles) and 4 WAV audio tracks.

| File | Bytes | Expected |
|---|---|---|
| `profile_720p30_1280x720_3frames.i420` | 4,147,200 | 1280×720×1.5×3 |
| `profile_1080p30_1920x1080_3frames.i420` | 9,331,200 | 1920×1080×1.5×3 |
| `profile_1080p60_1920x1080_3frames.i420` | 9,331,200 | 1920×1080×1.5×3 |
| `profile_1440p60_2560x1440_3frames.i420` | 16,588,800 | 2560×1440×1.5×3 |
| `profile_4K30_3840x2160_3frames.i420` | 37,324,800 | 3840×2160×1.5×3 |
| `video_main_1280x720_4frames.i420` | 5,529,600 | 1280×720×1.5×4 |

All 4 WAV files had a valid `RIFF`/`WAVE` header, and
`file_length == 44 + data_chunk_size`.

Every one of the 11 files had an identical SHA-256 in both runs; no missing
files, no size mismatches, no WAV header errors. Base tones are 440/880/1320/
1760 Hz with doubling on odd seconds (encoded in filenames and metadata).

`cargo test --workspace --all-targets`: 17 tests pass, including the new
profile-matrix unit test. `cargo clippy --workspace --all-targets -- -D warnings`
and `cargo fmt --all -- --check` pass.

## What was learned

- All three hypotheses were **confirmed**. The generator covers the full
  scenario matrix, emits four distinguishable audio tracks, and is
  byte-for-byte deterministic.
- Two clippy failures were found and fixed during the formal run
  (`unused variable fps`, `unused parameter cfg`); after the fix all checks
  pass. Recorded rather than hidden.
- Limitation: this validates file generation only. It does not prove that
  OBS, Teleport or Wormhole can ingest these files at the stated frame rates;
  that is a later integration test.

## Consequences

- Issues #17 (deterministic video generator) and #18 (multi-track audio
  generator) can be closed.
- The generated profile files are the inputs for the future S1–S10 benchmark
  runner. They are git-ignored (`exp_results/`) and regenerated by the command
  in HARNESS.md.
